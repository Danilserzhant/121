# H4 FVG на ETHUSDT Perp: вероятность реакции на тесте

Данные: Binance USDT-M Perp, 1h 2020-01-01 → 2026-09-15 03:00 UTC (последние 28 часов — Bitget perp,
базис к Binance −0.31$). H4 по границам Binance (00/04/08/12/16/20 UTC), 14 695 полных баров.

**FVG** — классический трёхсвечный: bull `low[i] > high[i-2]`, bear `high[i] < low[i-2]`.
**Тест** — первое касание ближней кромки (по часовым барам после закрытия бара i).
**Реакция ≥1 ATR** — после касания цена ушла от кромки на ≥1×ATR14(H4) *до* полного заполнения гэпа.
**held24** — дальняя кромка не пробита в течение 24 ч после касания.

## Что реально сдвигает вероятность

| фактор | худшая корзина | лучшая корзина |
|---|---|---|
| размер гэпа / ATR | <0.15 → 6.7% | >1 ATR → 55.0% |
| глубина захода первым часом | 100% (насквозь) → 0.2% | <25% → 51.2% |
| тело импульсной свечи / ATR | <0.5 → 9.8% | >2.5 → 60.7% (но n=56; при контроле на размер эффект исчезает) |
| по тренду (EMA50 H4) | против → 17.1% | по → 27.3% |
| возраст на момент теста | >30 д → 19.0% | 1–3 д → 29.9% |
| направление | bear 24.1% | bull 25.3% |

## Модель (логит на размере, импульсе, тренде, направлении, возрасте)

Обучение ≤2024 (1953 касаний), тест 2025–26 (660): **AUC 0.76** (react≥1ATR), **0.81** (held24).
Калибровка на тесте по квинтилям предсказания: 5→4%, 14→10%, 24→20%, 36→32%, 54→46% — модель
чуть оптимистична, порядок держит. Единственный весомый коэффициент — `log(size/ATR) = +1.06`.

# Часть 2. Критерии на 60–70% + синхронизация с M15

Исход считается **от закрытия подтверждающей M15-свечи** (момент входа), не от касания. Окно ожидания
подтверждения — 16 баров M15 (4 ч) после первого касания, до полного заполнения гэпа. M15 построен из минуток.

## Типы M15-подтверждения (в зоне H4 FVG)

| код | условие (для bull; bear зеркально) |
|---|---|
| 0 | без подтверждения — вход по закрытию M15-свечи касания |
| A | тень в зоне, закрытие обратно над ближней кромкой |
| B | свип минимума предыдущей M15 + закрытие выше него, в зоне |
| C | бычье поглощение M15 в зоне |
| **D** | **закрытие M15 выше максимума свечи касания** |
| E | три закрытия над кромкой без обновления минимума |

## Что дают подтверждения (все H4 FVG → size ≥ 0.5 ATR)

| подтв. | react≥1ATR все | react≥1ATR size≥0.5 | react≥0.5ATR size≥0.5 | held24 size≥0.5 |
|---|---|---|---|---|
| 0 без | 34.1% | 47.1% | 63.7% | 45.4% |
| A | 37.3% | 50.6% | 70.4% | 50.6% |
| B | 35.2% | 42.2% | 62.5% | 44.0% |
| C | 41.5% | 48.4% | 65.9% | 49.6% |
| **D** | **46.7%** | **57.2%** | **75.6%** | **59.2%** |
| E | 43.4% | 53.8% | 73.3% | 57.0% |

Свип-реклейм (B) — единственное подтверждение, которое **не помогает** (42% против 47% без него).

Лифт D над контролем стабилен во всех периодах (+5…+18 пп). Абсолютный уровень зависит от режима:
2020–21 завышает общую цифру, реалистичное ожидание вперёд — **60–67%**.

## Практика

- D появляется в **48%** тестов подходящих гэпов; медиана ожидания **45 мин** после касания, 90% — в пределах 3 ч.
- Остальные 52% тестов подтверждения не дают (пробой насквозь или уход без сигнала) — это фильтр, а не потеря.

## Предупреждение: 70% реакции ≠ прибыльная сделка

При тесном стопе за экстремумом теста и цели 1 ATR (нетто 0.1% комиссии):

| правило | 2020–21 | 2022–23 | 2024 | 2025–26 | всего |
|---|---|---|---|---|---|
| R1 | +0.51R | −0.20R | −0.24R | −0.08R | +0.12R |
| R2 | +0.34R | −0.18R | −0.22R | +0.02R | +0.04R |
| R3 (C, bull) | +1.04R | −0.11R | +0.01R | +0.15R | +0.33R |
| контроль без подтв. | +0.18R | −0.62R | −5.70R | −1.10R | −1.19R |

Реакция в 70% случаев приходит, но в ~половине из них цена сначала перепробивает экстремум теста
(выбивает тесный стоп), и только потом уходит. Со стопом за дальней кромкой винрейт ≈ вероятности
реакции, но RR падает до ~0.5. Структура выхода — отдельная задача.

# Часть 3. Расширенный поиск: контекст, новые подтверждения, выходы

Добавлены подтверждения **CH** (M15 CHoCH: закрытие над максимумом последних 3 M15 при устоявшем
минимуме теста), **NF** (вложенный M15 FVG в зоне), **A→D**, **D<50%**; признаки контекста (сессия,
выходные, свежесть, сторона EMA200, объём импульсной свечи / ср.20, растяжение от EMA50 в ATR);
восемь вариантов выхода + частичный. Правило принимается только при n ≥ 60 **и** реакции ≥55%
в каждом из трёх периодов (20–21 / 22–23 / 24–26). Перебрано 601 правило.

## Контекст (D, size ≥ 0.5): что двигает вероятность

| фактор | значения → react≥1ATR |
|---|---|
| **растяжение от EMA50 при формировании** | <1 ATR 52% · 1–2 57% · 2–4 54% · **>4 ATR 76%** (n=55) |
| **объём импульсной свечи / ср.20** | <1× **38%** · 1–1.5× 52% · 1.5–2.5× 59% · >2.5× 62% |
| сторона EMA200 | против 53% · по **59%** |
| свежесть ≤24 ч | свежий 56% · старый 63% |
| сессия касания | Asia 58 · London 56 · NY 59 · late 54 — не значимо |
| выходные | 57 / 57 — не значимо |

Цена: ~11 сделок в год.

## Оговорки

- Комбинации с растяжением найдены после просмотра однофакторных таблиц — это post-hoc, n=72–83.
  Реалистичное ожидание вперёд: реакция 60–65%, EV +0.1…+0.2R.
- «Лучший выход» выбран из восьми — селекция. Смотреть на минимум по периодам и на знак по всем выходам.
- Объём ≥2.5× сам по себе повышает реакцию, но EV не даёт (R-J ≈ −0.03R).

## 4. Почему 65% реакции ≠ прибыль (декомпозиция, стоп за экстремумом теста, цель 1 ATR)

| выборка | winrate | RR | риск % | EV без комиссии | мейкер | тейкер |
|---|---|---|---|---|---|---|
| H4 ETH CH ext≥4 | 56.6% | 1.37 | 1.52 | +0.41 | +0.39 | +0.34 |
| H4 5 монет CH ext≥4 | 47.2% | 1.23 | 1.64 | +0.12 | +0.09 | +0.05 |
| H1 3 монеты CH ext≥3 | 43.7% | 1.37 | 0.76 | +0.10 | +0.03 | −0.07 |
| H1 3 монеты любое ext≥3 | 39.4% | 1.57 | 0.59 | +0.11 | +0.02 | −0.12 |

«Реакция ≥1 ATR до заполнения гэпа» случается в 65%, но в трети этих случаев цена сначала
перепробивает экстремум теста и выносит тесный стоп. Итог: winrate 40–47% при RR 1.2–1.6 =
**+0.10 R брутто**. Это реальный, воспроизводимый, но тонкий эдж, который живёт только при
мейкерском исполнении. Больше ситуаций есть — больше денег на них нет.
