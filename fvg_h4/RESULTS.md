# H4 FVG на ETHUSDT Perp: вероятность реакции на тесте

Данные: Binance USDT-M Perp, 1h 2020-01-01 → 2026-09-15 03:00 UTC (последние 28 часов — Bitget perp,
базис к Binance −0.31$). H4 по границам Binance (00/04/08/12/16/20 UTC), 14 695 полных баров.

**FVG** — классический трёхсвечный: bull `low[i] > high[i-2]`, bear `high[i] < low[i-2]`.
**Тест** — первое касание ближней кромки (по часовым барам после закрытия бара i).
**Реакция ≥1 ATR** — после касания цена ушла от кромки на ≥1×ATR14(H4) *до* полного заполнения гэпа.
**held24** — дальняя кромка не пробита в течение 24 ч после касания.

## Что реально сдвигает вероятность

| фактор | худшая корзина | лучшая корзина |
|---|---|---|
| размер гэпа / ATR | <0.15 → 6.7% | >1 ATR → 55.0% |
| глубина захода первым часом | 100% (насквозь) → 0.2% | <25% → 51.2% |
| тело импульсной свечи / ATR | <0.5 → 9.8% | >2.5 → 60.7% (но n=56; при контроле на размер эффект исчезает) |
| по тренду (EMA50 H4) | против → 17.1% | по → 27.3% |
| возраст на момент теста | >30 д → 19.0% | 1–3 д → 29.9% |
| направление | bear 24.1% | bull 25.3% |

## Модель (логит на размере, импульсе, тренде, направлении, возрасте)

Обучение ≤2024 (1953 касаний), тест 2025–26 (660): **AUC 0.76** (react≥1ATR), **0.81** (held24).
Калибровка на тесте по квинтилям предсказания: 5→4%, 14→10%, 24→20%, 36→32%, 54→46% — модель
чуть оптимистична, порядок держит. Единственный весомый коэффициент — `log(size/ATR) = +1.06`.
