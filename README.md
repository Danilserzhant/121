# ATR Expansion Telegram Bot

Телеграм-бот, который сканирует все монеты биржи по свечам **1ч, 4ч, 1Д и 1Н**,
считает ATR и выводит те, у которых **ATR в % от цены самый высокий** — то есть
самое большое чистое движение за свечу. Отдельной командой можно посмотреть, у кого ATR
**расширился сильнее всего** (волатильность растёт). Все значения в **% от цены**,
а не в абсолютных единицах, поэтому монеты сравнимы между собой.

Пример вывода `/top`:

```
📊 Топ по ATR в % цены · 1ч
Биржа: binance_futures · свеча 04.09 15:00 UTC
ATR(14), сравнение с 24ч назад · 166 монет
 # Монета       ATR%    ΔATR  Свеча     Ход
 1 USELESS    10.14%   +113%  16.1%  +20.5%
 2 TRIA        6.80%   +351%   6.3%  +38.1%
 3 AZTEC       5.07%   +351%   7.6%  +14.1%
 ...
```

| Колонка | Смысл |
|---|---|
| **ATR%** | ATR(14): сглаженный по Уайлдеру true range каждой свечи, взятый в % от цены — средний «чистый» ход за свечу. По этой колонке сортируется `/top` |
| **ΔATR** | На сколько % текущий ATR% больше, чем ATR% N свечей назад (окно: 24ч, 6×4ч, 7 дней, 4 недели). По этой колонке сортируется `/exp` |
| **Объём** | Объём последней свечи к среднему объёму за окно, `x4.2` = в четыре раза выше обычного |
| **Топ** | Сколько свечей подряд монета держится в топ-20; `new` — только зашла |

Под таблицей кнопки: таймфрейм, ATR% / ΔATR, Long / Short / Все, 10 / 20 / 30 монет, Обновить.
| **Свеча** | True range последней закрытой свечи в % цены |
| **Ход** | Чистое движение цены (close→close) за окно сравнения |

## Как считается

1. Берутся только **закрытые** свечи (текущая незакрытая отбрасывается).
2. True Range = max(high−low, |high−prev close|, |low−prev close|), затем делится
   на предыдущий close — получается TR в % цены.
3. ATR% — сглаживание Уайлдера этих процентов с периодом `ATR_PERIOD` (14).
   Усреднение именно процентов, а не ценовых единиц, не даёт старым дорогим свечам
   раздувать ATR% после обвала цены.
4. Расширение = `ATR%_now / ATR%_{lookback свечей назад} − 1`, в %.
5. Неликвид отсекается по обороту за 24ч (`MIN_QUOTE_VOLUME`), стейблкоины исключены.

## Команды бота

| Команда | Что делает |
|---|---|
| `/top` | Топ по ATR% на часовых свечах |
| `/top 4h`, `/top 1d`, `/top 1w` | То же на 4-часовых, дневных, недельных |
| `/top 1d 30` | Таймфрейм и количество монет в любом порядке |
| `/top 1d long`, `/top short` | Только растущие или только падающие (чистый ход за окно вверх/вниз) |
| `/exp [тф] [N] [long/short]` | Топ по росту ATR (расширение волатильности) |
| `/atr SOL` | Одна монета на всех четырёх таймфреймах (можно `SOLUSDT`), кнопки ведут на график |
| `/chart SOL [тф]` | Картинка: свечи, ATR% и диапазон каждой свечи |
| `/watch SOL`, `/watch SOL ETH` | Следить за монетами: по ним приходят личные алерты |
| `/watchlist` | Мои монеты на часовике |
| `/unwatch SOL`, `/unwatch all` | Перестать следить |
| `/sub` | Часовой топ после закрытия каждой часовой свечи |
| `/sub 1d` | Дневной топ после закрытия дня (00:00 UTC) |
| `/sub alerts` | Алерты «свеча-выброс» по всему рынку |
| `/unsub [1h/1d/alerts]` | Отключить рассылку, без аргумента — все |
| `/subs` | Мои подписки |
| `/myid` | Свой Telegram ID и роль |

Работает и в личке, и в группах/каналах (добавьте бота и отправьте `/sub`).

## Алерты

**Свеча-выброс** (`/sub alerts`). После закрытия каждой часовой свечи бот ищет монеты,
у которых диапазон последней свечи ≥ `ALERT_TR_RATIO` (2.5) старых ATR и ≥ `ALERT_MIN_TR_PCT`
(1%) цены, и присылает список с объёмом и ходом. Это момент, когда волатильность
только просыпается, раньше, чем монета попадёт в топ по ATR%.

**Мои монеты** (`/watch`). По каждой монете из списка бот пишет в личку, когда:
- свеча ≥ `WATCH_TR_RATIO` (2×) старого ATR — один раз на свечу;
- ATR% вырос на ≥ `WATCH_EXPANSION_PCT` (50%) к окну сравнения — не чаще раза в 6 свечей.

Проверка идёт после закрытия часовой и дневной свечи.

## История топов

Бот запоминает топ-20 по каждому таймфрейму на каждую свечу (`HISTORY_TOP`). В колонке
«Топ» видно, кто держится третий час подряд, а кто только зашёл.

## Доступ и админка

Бот закрытый: отвечает только пользователям с ролью. Роли:

| Роль | Что может |
|---|---|
| **Владелец** | Всё, плюс назначать и снимать админов |
| **Админ** | Добавлять и удалять трейдеров, менять параметры сканера |
| **Трейдер** | Пользоваться ботом: `/top`, `/exp`, `/atr`, `/sub` |

Владелец задаётся через `OWNER_ID` в `.env`. Если он пустой, владельцем становится
первый, кто отправит боту `/start`. Пользователь без доступа получает в ответ свой ID,
который он передаёт админу.

Команды админов:

| Команда | Что делает |
|---|---|
| `/admin` | Справка по админке |
| `/users` | Список всех пользователей по ролям |
| `/requests` | Кто писал боту, но доступа не имеет |
| `/add_trader ID` или `/add_trader @username` | Дать доступ трейдеру |
| `/del_trader ID` или `@username` | Забрать доступ |
| `/add_admin ID` или `@username` | Назначить админа (только владелец) |
| `/del_admin ID` или `@username` | Снять админа (только владелец) |
| `/settings` | Текущие параметры сканера |
| `/set период 14`, `/set окно 4h 6`, `/set топ 20`, `/set оборот 10000000`, `/set atr 1.5` | Параметры сканера |
| `/set выброс 2.5`, `/set watch 2`, `/set рост 50` | Пороги алертов |

По `@username` можно добавить только того, кто уже писал боту. Иначе добавляйте
по числовому ID (`/myid`). При выдаче или отзыве доступа бот уведомляет пользователя.
Все роли и подписки хранятся в `data/store.json`.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN от @BotFather
python -m atr_bot
```

Проверить сканер без Telegram:

```bash
python -m atr_bot scan --top 20
python -m atr_bot scan -i 1d --top 20
python -m atr_bot scan --exchange okx --symbol sol
```

Docker:

```bash
cp .env.example .env
docker compose up -d --build
```

## Биржи

`EXCHANGE` в `.env`:

- `binance_futures` — USDT-M бессрочные контракты Binance (по умолчанию)
- `binance_spot` — спот Binance (с запасным хостом `data-api.binance.vision`, который не гео-блокируется)
- `bybit` — линейные бессрочные Bybit
- `okx` — USDT-свопы OKX

API-ключи не нужны, используются только публичные эндпоинты. Если Binance/Bybit
недоступны из вашего региона, задайте `EXCHANGE_PROXY=http://host:port` или
переключитесь на `okx`.
