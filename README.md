# ATR Expansion Telegram Bot

Телеграм-бот, который сканирует все монеты биржи по часовым свечам, считает ATR
и выводит те, у которых ATR **расширился сильнее всего** — то есть волатильность
растёт. Все значения показываются в **% от цены** (чистое движение), а не в
абсолютных единицах, поэтому монеты сравнимы между собой.

Пример вывода `/top`:

```
📊 ATR-расширение, 1h свечи
Биржа: binance_futures · свеча 04.09 15:00 UTC
ATR(14) сейчас vs 24 свеч назад · 166 монет
 # Монета       ATR%    ΔATR  Свеча     Ход
 1 AZTEC       5.07%   +351%   7.6%  +14.1%
 2 TRIA        6.80%   +351%   6.3%  +38.1%
 3 MERL        3.36%   +178%   4.8%   +5.9%
 ...
```

| Колонка | Смысл |
|---|---|
| **ATR%** | ATR(14) по часовым свечам, делённый на цену — средний «чистый» ход за час в % |
| **ΔATR** | На сколько % текущий ATR больше, чем ATR 24 свечи назад. По этой колонке сортируется топ |
| **Свеча** | True range последней закрытой свечи в % цены |
| **Ход** | Чистое движение цены (close→close) за окно сравнения |

## Как считается

1. Берутся только **закрытые** часовые свечи (текущая незакрытая отбрасывается).
2. True Range = max(high−low, |high−prev close|, |low−prev close|).
3. ATR — сглаживание Уайлдера с периодом `ATR_PERIOD` (14).
4. Расширение = `ATR_now / ATR_{lookback свечей назад} − 1`, в %.
5. Неликвид отсекается по обороту за 24ч (`MIN_QUOTE_VOLUME`), стейблкоины исключены.

## Команды бота

| Команда | Что делает |
|---|---|
| `/top [N]` | Топ N монет по расширению ATR |
| `/atr SOL` | Подробности по одной монете (можно `SOLUSDT`) |
| `/sub` / `/unsub` | Авторассылка топа после закрытия каждой часовой свечи |
| `/settings` | Текущие параметры |
| `/set период 14`, `/set окно 24`, `/set топ 20`, `/set оборот 10000000`, `/set atr 1.5` | Изменить параметр на лету (только `ADMIN_IDS`, если заданы) |

Работает и в личке, и в группах/каналах (добавьте бота и отправьте `/sub`).

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN от @BotFather
python -m atr_bot
```

Проверить сканер без Telegram:

```bash
python -m atr_bot scan --top 20
python -m atr_bot scan --exchange okx --symbol sol
```

Docker:

```bash
cp .env.example .env
docker compose up -d --build
```

## Биржи

`EXCHANGE` в `.env`:

- `binance_futures` — USDT-M бессрочные контракты Binance (по умолчанию)
- `binance_spot` — спот Binance (с запасным хостом `data-api.binance.vision`, который не гео-блокируется)
- `bybit` — линейные бессрочные Bybit
- `okx` — USDT-свопы OKX

API-ключи не нужны, используются только публичные эндпоинты. Если Binance/Bybit
недоступны из вашего региона, задайте `EXCHANGE_PROXY=http://host:port` или
переключитесь на `okx`.
